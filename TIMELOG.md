# Time log

Rough hours per part, as the assignment asks. The Hours column records the owner's focused working time: planning, directing agent work, reviewing code and documents, debugging, making decisions and preparing the submission. The work is AI-assisted throughout: Claude, an AI coding agent, writes most code and documents, and the owner directs, reviews and decides.

Autonomous agent development has its own elapsed runtime. Coding, tests and experiments can continue unattended in the background or overlap across parallel agent sessions. That background runtime and passive waiting are excluded from the owner's focused hours; active supervision, review and debugging are included. The dates retain the calendar span, while this table does not total background agent runtime. Application-run latency in the observability ledger is a separate measure from development-agent runtime.

The Iteration 3 entries are `UNREVIEWED_DRAFT`, prepared on an assumed-completion basis with the owner's rough hours. Release completion and its evidence remain recorded separately in the Master-Plan.
